# Habit Tracker

A simple Python command-line program for building and tracking daily habits. You can add habits, see whether you completed them today, mark them complete, and view your completion history. The program saves your data in a `habits.json` file.

## Features

- Add habits to your list
- View all habits and today's completion status
- Mark a habit complete for today
- View the dates when habits were completed
- Save data between runs using a JSON file

## Requirements

- Python 3.10 or newer
- Visual Studio Code or another code editor
- No extra Python packages are required

## Setup

1. Install Python from [python.org](https://www.python.org/downloads/).
2. Open the `Habit Tracker` folder in Visual Studio Code.
3. Make sure `main.py` and `README.md` are in the folder.
4. Open the VS Code terminal using **Terminal → New Terminal**.

## Run the program

In the terminal, run:

```bash
python main.py
